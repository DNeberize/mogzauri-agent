# მოგზაური (Mogzauri) — LLM აგენტი საქართველოში მოგზაურობისთვის

> AI კურსის პროექტი · **ეტაპი 1 — კონცეფცია და მუშა ჩონჩხი**

## რა პრობლემას ჭრის და ვისთვის

საქართველოში მოგზაურობის დაგეგმვისას ადამიანს ერთდროულად სჭირდება რამდენიმე წყაროს ნახვა: ამინდის საიტი
(მთაში — ყაზბეგი, სვანეთი — ამინდი გადამწყვეტია), ვალუტის კურსი (უცხოელებს ევრო/დოლარი აქვთ, ფასები ლარშია)
და ინფორმაცია ღირსშესანიშნაობებზე. **მოგზაური** არის ჩატ-აგენტი, რომელსაც ბუნებრივ ენაზე ეკითხები
(„შაბათ-კვირას ყაზბეგში მივდივარ, რა ამინდი იქნება და რა ვნახო?") და ის თავად წყვეტს, რომელი ხელსაწყო
გამოიყენოს, რეალურ მონაცემებს იღებს და მოკლე, პრაქტიკულ პასუხს აბრუნებს.

**მომხმარებლები:** ტურისტები საქართველოში, ადგილობრივები, რომლებიც შაბათ-კვირის გასვლას გეგმავენ.

## გამოყენებული მოდელი

- **`Qwen/Qwen2.5-3B-Instruct`** (Hugging Face), გაშვებული **ლოკალურად** `transformers`-ით — API გასაღები არ არის საჭირო.
- Qwen2.5 ოფიციალურად უჭერს მხარს tool calling-ს: ხელსაწყოების აღწერები (docstring-ებიდან) chat template-ით
  გადაეცემა მოდელს, ის კი აბრუნებს `<tool_call>{...}</tool_call>`-ს.
- მცირე GPU-სთვის (4 GB): `MODEL_ID=Qwen/Qwen2.5-1.5B-Instruct`. Colab T4-ზე შეიძლება `Qwen/Qwen2.5-7B-Instruct`-იც.
- მოდელის **გაწვრთნა არ ხდება** — ვიყენებთ წინასწარ გაწვრთნილ instruct მოდელს.

## აგენტის ტიპი: **მიზანზე ორიენტირებული (goal-based)**

- გარემო **ნაწილობრივ დაკვირვებადია** → simple reflex აგენტი არ გამოდგება; საჭიროა შინაგანი მდგომარეობა.
  ჩვენთან ეს მდგომარეობა არის **საუბრის ისტორია** (`self.messages`), ანუ აგენტი მინიმუმ model-based-ია.
- გარემო **თანმიმდევრულია** და ერთი შეკითხვა შეიძლება რამდენიმე ნაბიჯს მოითხოვდეს (მაგ. ჯერ ამინდი, მერე
  ინფორმაცია ადგილზე) → აგენტს აქვს **მიზანი** (მომხმარებლის მოთხოვნის სრულად შესრულება) და LLM თავად
  გეგმავს, რომელი ხელსაწყოს გამოძახებით მიუახლოვდება მას, სანამ მიზანს არ მიაღწევს (`MAX_STEPS`-მდე).
- **Utility-based** არ არის, რადგან ამ ეტაპზე ვარიანტებს შორის აშკარა სარგებლიანობის ფუნქციით არ ვარჩევთ
  (მაგ. „რომელი მარშრუტია უკეთესი ფასი/ამინდის მიხედვით") — ეს შეიძლება მე-2 ეტაპზე დაემატოს.
- **Learning** არ არის — მოდელი ჩვენ არ ვწვრთნით და გამოცდილებიდან არ სწავლობს.

## არქიტექტურა

```
მომხმარებელი ──► Agent.ask()
                   │  messages (ისტორია) + tools (docstring-ები)
                   ▼
              LocalLLM (Qwen2.5)  ──►  პასუხი ან <tool_call>
                   │                         │
                   │                 run_tool() ──► get_weather / convert_currency / search_wikipedia
                   │                         │
                   ◄──────── tool-ის შედეგი ◄─┘   (ციკლი, მაქს. 5 ნაბიჯი)
                   ▼
              საბოლოო პასუხი
```

**გადაწყვეტილებას იღებს ენის მოდელი** — კოდში არ არის `if "ამინდი" in text` ტიპის წესები. კოდი მხოლოდ
ასრულებს იმ ხელსაწყოს, რომელიც მოდელმა აირჩია, და შედეგს უბრუნებს მოდელს.

## ხელსაწყოები (tools)

| ხელსაწყო | რას აკეთებს | წყარო | ავტორი |
|---|---|---|---|
| `get_weather(city, days)` | ამინდის პროგნოზი 1–7 დღით | [Open-Meteo](https://open-meteo.com/) (უფასო, გასაღების გარეშე) | _სახელი_ |
| `convert_currency(amount, from_currency, to_currency)` | ვალუტის კონვერტაცია ეროვნული ბანკის ოფიციალური კურსით | [NBG API](https://nbg.gov.ge/) | _სახელი_ |
| `search_wikipedia(query)` | მოკლე ინფორმაცია ადგილზე/ღირსშესანიშნაობაზე | Wikipedia API | _სახელი_ |

თითოეულ ხელსაწყოს აქვს docstring (აღწერა, პარამეტრები, რას აბრუნებს) — სწორედ ეს docstring ეგზავნება
მოდელს ხელსაწყოს აღწერად. შეცდომისას ხელსაწყო აბრუნებს `ERROR: ...` ტექსტს, რომ მოდელმა მომხმარებელს გულახდილად უთხრას.

## გაშვება

### ვარიანტი A — Google Colab (რეკომენდებული)
1. გახსენით `colab_demo.ipynb` Colab-ში.
2. **Runtime → Change runtime type → GPU**.
3. გაუშვით უჯრები თანმიმდევრობით.

### ვარიანტი B — ლოკალურად
```bash
python -m venv .venv
.venv\Scripts\activate          # Linux/Mac: source .venv/bin/activate
pip install torch --index-url https://download.pytorch.org/whl/cu121   # CUDA GPU-სთვის
pip install -r requirements.txt
python test_tools.py            # ხელსაწყოების შემოწმება LLM-ის გარეშე
python main.py                  # ჩატი აგენტთან
```
პატარა GPU-ზე (4 GB): `set MODEL_ID=Qwen/Qwen2.5-1.5B-Instruct` (PowerShell: `$env:MODEL_ID="..."`).

Hugging Face token **საჭირო არ არის** (Qwen2.5 არ არის gated მოდელი).
